# 0.5.0-rc.2

增加单设备版 Windows 与 Mac 包。安装器为单设备版设置独立数据目录，主界面保留 Token 与额度功能，后台禁止设备配对、账号同步、共享文件夹和账本交换入口。

同步版延续 protocol v2 账本及 UL2 配对方式。增加 GitHub 构建、隐私扫描、测试与草稿发布流程。

本机验证报告随发布准备提供。Mac 原生安装、通知和真实 Windows 与 Mac 跨网络同步仍需维护者在实机完成验收，候选版标签保留 rc。

A「代码统计」图标已用于网页、快捷方式、托盘和 Mac 应用。Windows 与 macOS 云端自动检查通过，Mac 两种版本的原生编译、安装及签名验证通过。实际登录与真实双端跨网验收范围见 VALIDATION.md。
