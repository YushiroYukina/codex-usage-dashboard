# 统计口径

事件时间按 Asia/Shanghai 归日。累计 Token 通过相邻累计值的差额识别新增用量，重复事件、分支、续接和计数回退由日志解析器处理。模型名从会话与轮次元数据提取，无法确认时显示未知。

输入包含缓存输入。未缓存输入在字段充分时由输入减缓存得到。推理输出是否属于输出，结合实际总量等字段判断。原始缺失字段保留未知。缓存写入元数据可以保存，但不会额外计入 Token 总量。

额度变化使用同账号、同套餐、同重置窗口的可比较读数。跨重置、读数回退、过期读数和缺少边界采样会产生缺口。两位小数用于展示，实际精度由数据来源决定。Token 与额度百分点分别展示。

原生账号累计值、峰值和原生日期桶遵循来源口径，原生时区不明确时保留其日期。同步版原生账号数据按观察记录合并，当前额度采用最新实际观察值。

本机日志仅代表本机留下的记录。同步后的覆盖范围扩展至已导入的配对设备记录。历史缺失部分需要实际数据来源补充。普通 Chat 与未留下本地记录的云端任务可能未被覆盖。

跨端事件按稳定 ID 去重，冲突使用事务回滚。轮次关联随账本保存。双方确认的修订和摘要代表当次账本快照，新记录出现后状态返回待同步。
